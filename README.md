# HiveMind
Jas's AI Harness

The harness that drives a local-model build line. Tasks are scoped into briefs, built by local models in a sandbox,
gated by tests, reviewed and merged. This repository holds the harness code and its open harness tasks, so that
cloud sessions can work on them. Finished branches are reviewed and merged in the origin repository.

- Task list: [`tasks/INDEX.md`](tasks/INDEX.md)
- How to work a task: [`CLAUDE.md`](CLAUDE.md)

Personal details, addresses and private data were removed from this export. Hosts and addresses in the code are
placeholders (`example.invalid`, `192.0.2.x`, `100.64.0.x`).
